# Prototype F — Calculator V2 理性购房决策器

按 [docs/CALCULATOR_V2_SPEC.md](../../docs/CALCULATOR_V2_SPEC.md) 实现的**完整可点击前端原型**。

源文件：[index.html](./index.html) — 浏览器直接打开，**包含 mock 计算引擎**（前端 JS 实现），无需后端。

## 流程概览

```
Hero → Step 1（身份/套数/年龄）→ Step 2（收入/现金/CPF）→ Step 3（时间线）→ Loading → 结果页
```

**最多 7 题，最少 6 题**（外籍跳过 CPF）。所有默认值（年龄 35 / 贷款 30 年 / 持有 7 年 / 利率 1.65%）按 spec 设置。

## 结果页 3 大 block

### ① 三档房价区间
- 舒适（月供 ≤ 30%）/ 平衡（≤ 35%，**推荐**）/ 极限（≤ 55% MAS 上限）
- 点击切换，下方 block 2 + 3 联动重算

### ② 现金需求拆解
- 首付现金部分（5% 必须）+ CPF 抵扣 + BSD + ABSD + 杂费
- **应急金独立显示**（12 月家庭开销）
- **可行性判断**：现金够 → 绿色"放心进场"；现金不足 → 暖色诊断面板（3 条出路）
- 外籍诊断面板自动换成"拿到 PR 后再买"

### ③ 买 vs 租 break-even（**仅首套显示**）
- 同档位市场月租（默认估算，**可直接编辑**）
- 4 个微调参数：年数（5/7/10/15）· 贷款年限（20/25/30）· 利率（滑块 1.5–4%）
- 输出大字：年涨 ≥ **X%** 买才划算
- 历史涨幅参考（新加坡私宅过去 10 年 2.8%/年）

## Mock 引擎实现了什么

完整在 [index.html](./index.html) 末尾 `<script>` 块：

| 函数 | 用途 |
|---|---|
| `bsd(price)` | BSD 累进 6 档完整计算 |
| `absd(price, residency, count)` | ABSD 矩阵（SC/PR/外籍 × 1/2/3+ 套）|
| `ltvCap(age, tenure, count)` | LTV 75% / 55% / 45% 三档 |
| `pmt(P, r, n)` | 月供（PMT 公式）|
| `maxLoanFromMonthly` | TDSR 反推最大贷款 |
| `solveAtRatio(ratio)` | 二分搜索：给定月供占比，求最大房价 |
| `evaluatePrice(price)` | 给定房价，输出全数字（首付/BSD/ABSD/月供）|
| `computeTiers()` | 生成 3 档区间 |
| `computeBreakEven(price)` | **核心**：二分搜 g*，使买房 H 年净资产 = 租房 H 年净资产 |
| `estimateMedianRent(price)` | 房价 × 2.7% 年化租金回报估算月租 |

### Break-even 模型

```
买房 H 年后净资产 = price × (1+g)^H × (1-2%) − 剩余贷款 − 累计利息/MCST/房产税/维护
租房 H 年后净资产 = (首付+税) × (1+5%)^H + 月省下钱的复利收益 − 累计租金
求 g* 使两者相等
```

替代投资回报默认 5%（标普 500 长期保守）。

## 已知简化

mock 引擎相比真实后端引擎做了几处简化（仅原型用，**不影响 UX 评审**）：

- 区间下界用上一档上限粗略估算（真实版应按月供占比 25% / 32% 倒推）
- 应急金按 "月入 × 0.55 × 12" 估算（应基于真实月支出问卷）
- 租金中位数用"房价 × 2.7% / 12"（真实版应接 URA 季度租赁数据）
- Break-even 模型只考虑核心变量，未含 SSD / 个税 / CPF 增值收益
- 利率默认值 1.65%（应接 SORA 实时）
